# Drop your photo here

Save your photo as `abdul-rahman.jpg`, then enable it in `src/data/site.ts`:

```ts
photo: {
  src: "/images/abdul-rahman.jpg",
  enabled: true,   // <- flip to true
},
```

While `enabled` is `false`, the About section shows an "AR" initials placeholder.

## Recommended specs

- Format: `.jpg` or `.webp`
- Dimensions: 800 x 1000 (4:5 portrait)
- Under ~300 KB (compress before adding)
